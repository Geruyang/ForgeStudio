# 支持矩阵（Support Matrix）

> QA（Agent D）维护。首发（v0.1.0）支持范围、签名状态与未测组合。如实标注，不夸大。
> 依据：任务书 §4.3（首发范围）、§15.3（交付清单）；docs/ENVIRONMENT.md（实测环境）。

## 1. 操作系统

| 平台 | 状态 | 说明 |
|---|---|---|
| **Windows 11 x64** | **唯一认证平台** | 开发与验收机（build 26200） |
| Windows 10 x64 | 未验证 | 未测；不列入支持矩阵（任务书 §15.2 should：中文/空格等路径组合之外的未测组合同样处理） |
| Windows 11 ARM64 | 未验证 | 未测；vendored codex 为 win32-x64 平台包，ARM64 需另行适配 |
| Linux / macOS | 不支持 | 本产品为 Windows 工程工作台 |

## 2. 运行前提

| 项 | 状态 | 说明 |
|---|---|---|
| Node.js 运行时 | 不要求用户安装 | 随包 Electron 作为 Node 运行时（`ELECTRON_RUN_AS_NODE`，DECISIONS D3） |
| **MXC 沙箱** | **未预置** | 未获得管理员授权执行 sandbox setup 探测；设备操作走"引擎审批之外独立授权 + 执行器强制校验"，**不宣称"受控自主设备操作"** |
| git | **可选** | 运行时探测：有 git 自动启用（证据含 gitCommit/dirtyDiffDigest）；无 git 走完整输入清单内容摘要（A 级指纹仍成立，`hasGit=false` 标明） |
| probe-rs / 烧录工具链 | T2 运行前提 | 首发未安装；诊断面板显示 `probeRsAvailable=false` 并给出缺失提示 |
| 串口驱动 | T2 运行前提 | 无目标设备接入时 `serialPortsAvailable=false` |

## 4. 任务类型支持

| 任务类型 | 状态 | 前提 |
|---|---|---|
| T1 软件任务（构建/测试/证据/导出） | 首发目标 | 已认证平台即可 |
| T1 模型驱动软件修复 | 阻塞中 | 需模型凭证（API key 或账号登录；见 KNOWN_ISSUES K-1） |
| T2 嵌入式（构建→烧录→串口验证） | **需实机前提** | 板卡 + 探针 + probe-rs + 授权烧录；当前无硬件（K-2），保留未完成 |
| T2 跨域（固件协议 + 上位机） | 需实机前提 | 同上，可共用一个工程 |

## 5. 未测组合（不列入已验证范围）

- Windows 10 任意版本；ARM64。
- 非 per-user（per-machine）安装方式。
- 多型号/多端口热插拔身份变化（M6 扩展项）。
- 长时间串口流与旧日志边界组合（M6 扩展项）。
- 中文、空格等特殊路径的安装/样例路径之外的组合（首发实际安装路径必须通过，其余未测即标限制）。
- 第二 Windows 用户全项安装回归（无项目开发环境可启动、缺外部工具有诊断——未执行）。
- 多版本共存、迁移与大交付包导出压力（M1 扩展项）。
- B 级快照构建与外部并发修改（T3 顺延，未启用 B 级声明）。
